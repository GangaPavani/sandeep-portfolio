# Sandeep Kumar - Portfolio Website

A modern, responsive portfolio website built with React 18, Vite, and Tailwind CSS showcasing Sandeep Kumar's professional experience as a ServiceNow Developer.

## 🚀 Features

- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Fast Performance**: Built with Vite for lightning-fast development and builds
- **Modern UI**: Clean, professional design with smooth animations
- **Comprehensive Sections**:
  - Professional Summary
  - Employment History
  - Key Projects
  - Technical Skills
  - Education
  - Certifications
  - Contact Information

## 📋 Prerequisites

- Node.js (v14 or higher)
- npm or yarn

## 🔧 Installation

1. Clone or download this repository
2. Navigate to the project directory:
   ```bash
   cd Portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## 🏃 Running the Project

### Development Server

Start the development server on http://localhost:5173:

```bash
npm run dev
```

### Production Build

Create an optimized production build:

```bash
npm run build
```

### Preview Build

Preview the production build locally:

```bash
npm run preview
```

## ✏️ Customization

### Updating Portfolio Content

Edit the `src/data/portfolioData.js` file to update:

- Personal information (name, location, contact details)
- Professional summary
- Employment history
- Projects
- Skills
- Education
- Certifications

### Styling

Tailwind CSS classes are used throughout the project. Customize colors and styles in `tailwind.config.js`.
